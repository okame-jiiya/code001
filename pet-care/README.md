# うちの子ごはん帳（Android）

猫と犬のごはん（カロリー）とトイレ（うんち・おしっこ）を記録する Android アプリです。
アカウント登録・広告なし。データはスマホの中に保存され、家族共有をオンにしたときだけクラウド（Firebase）にも置かれます。

## インストール

[pet-care-latest リリース](https://github.com/okame-jiiya/code001/releases/tag/pet-care-latest) から
`PetCare-debug.apk` をスマホでダウンロードして開きます（初回は「提供元不明のアプリ」の許可が必要です）。
Android 8.0 以上で動きます。

## できること

- **うちの子の登録**：種類（猫・犬）、品種、名前、性別、体重、生年月日または年齢、避妊・去勢の有無。複数頭の切り替えに対応
- **体形の選択**：一般的な BCS 表と同じ「横から見た図」と「上から見た図」のイラスト 5 段階（BCS 1〜5）から選ぶ
- **品種**：猫 54 種・犬 122 種の候補をアイウエオ順で表示（絞り込み可、リストにない品種は自由入力）
- **フード・おやつの登録**：「100 g あたり 380 kcal」「1 袋あたり 70 kcal」のように単位とカロリーを登録。
  g 単位で量を調整できるもの（カリカリ）と、個数単位のもの（パウチ・缶・ちゅ〜る）を区別
- **ごはんプラン**：フードごとに「何日に何回」あげるかを決めると、1日の目安カロリーから
  パウチなど量が決まっている分を差し引き、残りをカリカリの g 数で自動計算。おやつが目安の 10% を超えると警告
- **ワンタップ記録**：「あげた」「うんち」「おしっこ」を 1 タップで記録（取り消し・時刻の修正も可能）
- **カレンダー**：ごはんは日ごとの合計 kcal を色分け（少なめ／ちょうど／多め）、トイレは日ごとの回数を表示。
  通院・お薬・ワクチン・トリミングなどの予定は種類別の色ドットで表示。
  日付を選んだら「いま」か「ごはんの時刻」（「設定」で変更可）を選び、ごはん・うんち・おしっこをワンタップで記録できます。
  押し間違えたら「↩ 取り消す」で新しい順に戻せます
- **きげん**：晴れ・曇り・雨からワンタップで記録。カレンダーでは日付の右肩に小さく表示
- **トイレの状態メモ**：うんちのかたさ（コロコロ〜水っぽい）、おしっこの量（出ない〜多い）、
  色・血・粘液・寄生虫らしきもの・にごり・回数・痛がる様子など、動物病院でよく聞かれる項目をチェック。
  気になる記録があった日はカレンダーに ⚠ が付き、おしっこが 24 時間以上記録されていないときは「きょう」画面で注意を表示
- **体重の記録とグラフ**：1か月／3か月／1年／すべての折れ線グラフ。目標体重（または体形から推定した理想体重）を点線で表示。
  いちばん新しい体重がカロリー計算に使われます
- **通院・お薬・ワクチン・トリミング**：予定の時刻と通知のタイミング（前日の◯時／当日の◯時間前）を選べる。
  2 週間以内の予定は「きょう」画面にも表示
- **多頭飼い**：上部のボタンで切り替え。アイコンは写真の縮小版（標準）か、絵柄と色を子ごとに選べます。
  「うちの子」画面は全員の一覧から、1頭ずつのプロフィールと記録の推移へ
- **まとめ（ダッシュボード）**：体重・カロリー・トイレ回数・機嫌・選んだ記録項目・支出の推移を、全員を重ねて、または1頭ずつ表示。
  支出は子ごと・みんなの分・全体の合計
- **画面の表示**：「設定」で、下のタブ・各画面のカードの順番と表示する／しない、カレンダーのマスや写真の大きさを変えられます
- **記録する項目を選べる**：「設定」で体重・体温・ごはん・水・うんち・おしっこ・機嫌・散歩・フィラリア予防・混合ワクチン・
  狂犬病ワクチン・通院記録・薬（飲ませた／内容）・体調不良・ブラッシング・トリミング・シャンプー・爪切りから選択。どれも日付と時刻つきで記録
- **カレンダーの切り替え**：上で「ごはん・排泄／日記／予定／支出」を選び、日付をタップしてすぐ登録。
  マスに出す内容（カロリー・トイレ回数・機嫌・記録・予定・日記・支出）は「👁 表示」のチェックで選べます
- **定期リマインダー**：ごはん・おやつ・薬・通院・散歩・体重などをまとめてオンにし、「○時間ごと・毎日・○日ごと・毎週」を組み合わせて通知
- **プロフィール**：お迎え日、性格・体の特徴・そのほかのメモ、トップ画像（アイコンにもできる）、診断書・血統書などの画像。
  写真はアプリ内で位置・大きさ・回転を調整し、家族共有で送れるよう小さく圧縮して保存
- **トイレの写真**：獣医さんに見せる用に、うんち・おしっこの記録に写真を付けられます（圧縮して保存）
- **PDF形式で出力**：プロフィールや毎日の記録を、入れる内容と期間を選んで PDF にし、LINE やメールで送ったり保存したりできます（提出などに）
- **並べ替え**：うちの子の登録・編集・表示順は「設定」にまとめています（手動、または「犬→猫・年上から」などで自動）
- **文字の大きさ**：「設定」で 4 段階
- **バックアップ**：全データを JSON ファイルに書き出し・読み込み（機種変更のときなど。写真はファイルに含まれません）
- **家族共有と Web 版**：「設定」画面で共有を始めると QR コードが出ます。家族のスマホで読み取ると、
  アプリがあればアプリで、なければ Web 版（iPhone でも可）で同じ記録を読み書きできます。どちらかが記録するとすぐ反映されます
- **Web 版でできること**：アプリと同じ「きょう・カレンダー・ごはん・うちの子・まとめ・設定」の画面があり、記録の取り消し、推移のグラフ、
  うちの子の登録・編集、フードやごはんプラン、ごはんの時刻、PDF 形式での出力（ブラウザの印刷から）もできます。
  画面の並び・文字の大きさはブラウザごとに覚えます。通知（リマインダー）とバックアップはアプリだけの機能です

## カロリー計算式

- RER（安静時エネルギー要求量）= 70 × 体重(kg)^0.75
- 1日の目安（MER）= RER × 係数

| | 犬 | 猫 |
|---|---|---|
| 生後4か月未満 | 3.0 | 3.0 |
| 生後4〜12か月 | 2.0 | 2.5 |
| 避妊・去勢済みの成年 | 1.6 | 1.2 |
| 未去勢の成年 | 1.8 | 1.4 |
| シニア（犬7歳以上） | 1.4 | 成年と同じ |
| 減量（BCS 4・5） | 1.0 | 0.8 |

BCS が 3 以外の成年・シニアは、BCS が 1 段階ずれるごとに体重が約 15% ずれるとみなして理想体重を推定し、
その体重で計算します（目標体重を入力した場合はそちらを優先）。1日のカロリーを手動で設定することもできます。

## 家族共有のしくみ

- 記録は Firebase（Google の無料サービス）の Firestore に、記録 1 件ずつ保存します。2 人が同時に書いても消し合いません
- 最初は端末ごとの匿名ログインで、Google アカウントにつなぐと、機種変更や入れ直しのあとも招待なしで家族に戻れます
- 家族のメンバー（`members`）だけが記録を読み書きできます。メンバーになれるのは共有を始めた人と、
  期限内（7 日）の招待リンク（`https://okame-jiiya.github.io/code001/#join=家族.招待`）を受け取った人だけです。
  招待はいつでも取り消せ、知らないメンバーは「外す」で外せます（ルールは `firebase/firestore.rules`）
- 不正利用対策として App Check（アプリは Play Integrity、Web は reCAPTCHA Enterprise）を組み込んでいます
- Web 版は `web/` にあり、push すると GitHub Actions が `gh-pages` ブランチに置き、GitHub Pages で公開されます
- Firebase の設定は `firebase-config.json`（公開しても問題ない値）に置きます。
  このファイルが無いビルドでは、共有機能は「準備中」と表示されます。設定手順は `firebase/README.md`
- APK は `app/debug.keystore`（デバッグ用の固定の鍵）で署名するので、新しい版を上書きインストールできます
