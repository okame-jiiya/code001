# Yahoo!オークション 自動延長なし抽出ツール

Yahoo!オークションでカテゴリ・条件検索した結果の中から、「自動延長」が「なし」の商品だけを画像付きで一覧表示し、
①クリックで商品ページを開く／②その場でウォッチリストに追加、ができるTampermonkeyユーザースクリプトです。

## なぜユーザースクリプトなのか

ウォッチリストへの追加にはYahoo!のログインセッション（Cookie）が必要なため、サーバー側で動く独立ツールでは実現できません。
本ツールはブラウザ上でログイン中のセッションをそのまま使うユーザースクリプトとして実装しています。

## インストール方法

1. Chrome/Edge/Firefoxに [Tampermonkey](https://www.tampermonkey.net/) 拡張機能を入れる
2. Tampermonkeyの管理画面から「新規スクリプトを作成」を選び、`yahoo-auction-no-extend-picker.user.js` の中身を貼り付けて保存
   （またはこのファイルをブラウザで直接開くとTampermonkeyがインストール画面を出します）
3. Yahoo!オークションにログインしておく

## 使い方

1. Yahoo!オークションで、いつも通りカテゴリ選択＆条件検索を行い、検索結果一覧を表示する
2. 画面右下に出る「自動延長なしを抽出」パネルの「自動延長なしを抽出」ボタンを押す
   - 検索結果の次ページも合わせてチェックしたい場合は「追加取得ページ数」に0〜9の数字を入れてから実行する
3. 各商品の詳細ページを裏側で取得して「自動延長」の有無を確認するため、件数に応じて数秒〜数十秒かかる
4. 完了するとモーダルで「自動延長なし」の商品だけが画像付きで一覧表示される
   - 行をクリック（ウォッチボタン以外の部分）→ 商品ページが新しいタブで開く
   - 「☆ウォッチ追加」ボタンをクリック → ページ遷移せずにその場でウォッチリストに追加を試みる

## 既知の制約・注意点

- **「自動延長」は検索結果一覧には表示されず、商品詳細ページにのみ表示される情報**のため、一覧に出てきた商品ごとに
  詳細ページを1件ずつ取得してチェックしています。件数が多いページや複数ページ指定時は時間がかかります。
  サーバーへの負荷を抑えるため、同時リクエスト数を3件・リクエスト間隔を350msに制限し、判定結果は12時間キャッシュしています。
- **ウォッチリストへの「その場で追加」は、非表示のiframeで商品詳細ページを開き、Yahoo自身の「ウォッチリストに追加」ボタンを
  自動クリックする方式**です。この方式はYahoo側が同一オリジンでのiframe埋め込みを許可している場合のみ動作します。
  もし許可されていない場合や、ボタンが自動検出できなかった場合は、「手動で開く」ボタンが表示されるので、
  そこから商品ページを開いて手動でウォッチリストに追加してください。
- この開発環境からはネットワークポリシーによりYahoo!オークションへ直接アクセスできず、実際のページHTMLで動作検証ができていません。
  そのため、商品一覧の抽出・自動延長の判定・ウォッチボタンの自動検出は、いずれもYahoo側のページ構造の変化で
  動かなくなる可能性があります。うまく動かない箇所（例:「価格が拾えない」「ウォッチボタンが見つからない」等）があれば、
  ブラウザのコンソール（F12）のエラー内容と合わせて教えてください。`yahoo-auction-no-extend-picker.user.js` 冒頭の
  `CONFIG` オブジェクトのセレクタを調整することで対応できます。
- 短時間に大量のページ・商品を処理すると、Yahoo!オークション側の利用規約やアクセス制限に抵触する可能性があります。
  個人利用の範囲で、常識的な件数・頻度での利用を推奨します。
