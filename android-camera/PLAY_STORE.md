# Google Play 公開チェックリスト（BlackCam）

コード側の準備は済んでいます。Play Console での作業と、アカウント所有者にしかできない作業を整理します。

## 1. 署名とビルド

1. アップロード鍵（keystore）を作成します（Play App Signing を使う場合、これは「アップロード鍵」で構いません）。
   ```sh
   keytool -genkeypair -v -keystore upload.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000
   ```
2. GitHub のリポジトリ設定 → Secrets and variables → Actions に次の 4 つを登録します（鍵はリポジトリに置かないでください）。
   - `BLACKCAM_KEYSTORE_BASE64`（`base64 -w0 upload.jks` の出力）
   - `BLACKCAM_KEYSTORE_PASSWORD` / `BLACKCAM_KEY_ALIAS` / `BLACKCAM_KEY_PASSWORD`
3. `main` 系のブランチに push すると、Actions が署名済みのリリースバンドルを作り、成果物 `BlackCam-release-aab`（7 日間保存）に出力します。これを Play Console にアップロードします。
   `versionCode` は Actions の実行番号が自動で入ります。

## 2. Play Console の申告

- **アプリのコンテンツ → データセーフティ**: データの収集・共有は「なし」。
- **プライバシーポリシー**: `PRIVACY.md` を公開した URL を登録します（GitHub Pages などで公開してください）。
- **前面サービスの権限の申告**: 種類は「カメラ」「マイク」。説明例:
  > ユーザーがアプリを閉じた（ホーム画面に戻る・画面をロックする）直後に、録画中の動画ファイルを最後まで書き込んで端末に保存するため。保存が終わるとサービスは自動で停止します。
  申告には、アプリを閉じたあとも保存が続く様子の短い動画が必要になることがあります。
- **ターゲット層・コンテンツのレーティング**: アンケートに回答します。
- **権限の説明**: カメラ・マイクは動画撮影のため。

## 3. ストア掲載で注意すること（審査対策）

本アプリは「画面を黒くして録画する」ため、Play のポリシー（隠し撮り・スパイウェアの禁止）に注意が必要です。

- ストア説明に「バッテリー節約のために画面を黒くして録画するドライブレコーダー／記録用アプリ」であることを明記し、**他人を無断で撮影しないこと**を注意書きします。
- 録画中の小さな赤い点（設定で既定オン）と、保存中の通知は、審査で「録画していることが分かる」根拠になります。既定のオンを変えないことを推奨します。
- Android 12 以降は、カメラ・マイク使用中に OS が緑のインジケーターを表示します。

## 4. 掲載文の素材

- 短い説明: 起動するとすぐ録画を始め、画面を真っ黒にして電池を節約する録画カメラ。
- 画面キャプチャ: 設定パネル、カメラ選択画面（性能表示と試し撮りの結果）を撮影してください。
- アイコン: 512×512 の PNG は Play Console 用に別途用意が必要です（アプリ内のアイコンは適応型アイコンで用意済み）。

## 5. 対応端末

Android 11 (API 30) 以降のカメラ付き端末。カメラ構成は起動時に調べて設定画面に出し、設定が通らない端末では標準設定（フルHD・30fps・H.264）に自動で切り替えて録画します。
